### 更新内容

- 新增 `sql_analytics`（界面名称“智能问数”）知识库类型，并删除代码中的旧类型映射（后端 `ac52ab7`、前端 `81c5afb`）。
- 支持按文件节点范围进行知识库检索（`fe32e89`）。
- 删除文件时级联硬删除 Chunk，并同步删除检索索引（`ce008d2`）。
- Chunk 编辑提交后重建文件索引，保持主表、修订版本与索引一致（`652a876`）。
- 文档详情新增当前解析代际的结构化分析接口，前端按真实摘要、业务流程、关键字段/实体、目录层级和知识条目展示，并支持点击图谱节点查看属性、关系及定位原文（前端 `f2cd71f`，后端本次提交）。

本版本相对生产基线未新增版本化 SQL 文件；上线时仍需核对生产库已有基础表及代理种子数据，不得据此推断“无需数据库检查”。
